# Painting With Purpose — Demo 1

Static concept site (no build step). Open `index.html` or deploy the folder to GitHub Pages, Netlify or Vercel as-is.

## Pages
- `index.html` home · `work.html` project grid + index · `project-*.html` seven case studies
- `services.html` · `purpose.html` · `careers.html` · `contact.html`

## Images
- `assets/img/` client photos (2400px + 1100px `-md` versions)
- `assets/art/` watercolor artwork from ChatGPT. Drop files in with these names and they appear automatically; until then a painted placeholder shows:
  `w01-hero-panorama.jpg` (in place) · `w02-farmhouse.jpg` · `w03-divider.jpg` · `w04-exterior.jpg` · `w05-interior.jpg` · `w06-commercial.jpg` · `w07-map.jpg` · `w08-swatches.jpg` · `w09-sunrise.jpg` · `w10-dusk.jpg`
- `assets/ba/` before/after pairs: `ba1-before.jpg` + `ba1-after.jpg` … `ba4-*`

## Notes
- Forms are demo-only (no backend). Wire to Formspree/Netlify Forms when going live.
- Project names, locations and job details are draft copy for client review.
