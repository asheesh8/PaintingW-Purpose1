# Painting With Purpose — Demo 1

Minimal, photo-led static site (no build step needed to deploy). In the spirit of foundry-house.com and birdseyevt.com: four photographs carry the whole home page, and the feeling comes from moving through it rather than from more pictures. Type is Instrument Serif (upright only) + Geist; navy `#105677` and sky `#68ABE4` come from the logo.

## The four heroes
| Slot | Photo | Motion |
| --- | --- | --- |
| `sigma` | Sigma Phi House (DSC_0179) | home hero, slow dolly-in |
| `victorian` | Queen Anne Victorian (DSC_0058) | small inset that opens to full screen as you scroll |
| `library` | Library interior (DSC_0995) | sticky split beside Interiors / Commercial / Historic |
| `porch` | Built-ins & porch (DSC_1371) | closing "Start a project" screen and the contact page |

Stills live in `assets/hero/{slot}-wide.jpg` (2560×1440) and `{slot}-tall.jpg` (1080×1920, used when the screen is taller than 4:5).

### Hero clips (silent, one per page)
Each clip is used once, so no page carries more than one video:
- `sigma.mp4` plays behind the home hero (the other three home screens stay photographs)
- `victorian.mp4` heads the Queen Anne Victorian project page
- `library.mp4` heads the Library project page
- `porch-tall.mp4` sits beside the contact form

Prepare each raw clip with `sh tools/prep_clip.sh raw.mp4 assets/hero/sigma.mp4` (first 3.5s played forward then backward, so the loop has no jump; audio removed; small H.264). Add a `-tall.mp4` portrait version if you have one, otherwise phones crop the landscape clip. Then run `python3 tools/build.py`. The build only adds a `<video>` when the file exists; it plays muted, starts when it scrolls into view and fades in over the still.

## Logo
`assets/logo.png` is used in the header and footer. Swap the file to update it everywhere.

## Pages
`index.html` · `work.html` (text index, a photo follows the cursor) · seven `project-*.html` (one lead photo, then text) · `transformations.html` (before & after) · `services.html` · `purpose.html` · `careers.html` · `contact.html`

## Editing
Pages are generated by `tools/build.py` (copy lives there; project facts in `tools/projects.json`, before/after pairs in `tools/transformations.json`). Edit, then run `python3 tools/build.py` from the repo root.

## Images
- `assets/hero/` the four hero stills (and clips when added)
- `assets/img/` client photos (2400px + 1100px `-md`); each project's lead photo is set by `LEAD` in `tools/build.py`
- `assets/ba/` before/after pairs
- The watercolors were removed in the minimal pass. Photos DSC_0735 and DSC_1343 are not used.
