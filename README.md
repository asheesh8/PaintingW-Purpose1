# Painting With Purpose — Demo 1

Static site laid out after [birdseyevt.com](https://birdseyevt.com) (no build step needed to deploy): a thin cream header with a drop-down menu, a home page that is simply a stack of full-width project photographs, dark project pages with numbered notes beside a column of photographs, and a beige footer. Type is Gambetta + Switzer (Fontshare); colors are cream `#F5F4E9`, charcoal `#393532` and beige `#DED7C7`. All photographs and copy are Painting With Purpose's own.

## Logo
`assets/logo.png` is the current PWP logo and is used in the header and footer. Swap the file to update it everywhere.

## Pages
`index.html` · `work.html` · seven `project-*.html` · `transformations.html` (before & after) · `services.html` · `purpose.html` · `careers.html` · `contact.html`

## Editing
Pages are generated by `tools/build.py` (copy lives there; project facts in `tools/projects.json`, before/after pairs in `tools/transformations.json`). Edit, then run `python3 tools/build.py` from the repo root.

## Images
- `assets/img/` client photos (2400px + 1100px `-md`), lightly graded for a consistent look
- Project photo sequences (`GROUPS`) and the home page order (`ORDER`) are set at the top of `tools/build.py`
- `assets/ba/` before/after pairs
- Forms are demo-only (no backend).
