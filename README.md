# Painting With Purpose — Demo 1

Photo-led static site (no build step needed to deploy). The home page runs hero to hero: each project fills the screen and the next slides up over it. The Vermont watercolors (`assets/art/`) are painted in behind the content with `mix-blend-mode: multiply`, so the paper melts into the page. Birdseye (birdseyevt.com) was the inspiration for the restraint and the project pages. Type is Instrument Serif + Geist; navy `#105677` comes from the logo.

## Logo
`assets/logo.png` is the current PWP logo and is used in the header and footer. Swap the file to update it everywhere.

## Pages
`index.html` · `work.html` · seven `project-*.html` · `transformations.html` (before & after) · `services.html` · `purpose.html` · `careers.html` · `contact.html`

## Editing
Pages are generated by `tools/build.py` (copy lives there; project facts in `tools/projects.json`, before/after pairs in `tools/transformations.json`). Edit, then run `python3 tools/build.py` from the repo root.

## Images
- `assets/img/` client photos (2400px + 1100px `-md`), lightly graded for a consistent look
- Project photo sequences (`GROUPS`), the home page order (`ORDER`) and the watercolor behind each project (`ART`) are set at the top of `tools/build.py`
- `assets/art/` watercolor illustrations, placed with `art()` in `tools/build.py`
- `assets/ba/` before/after pairs
- Forms are demo-only (no backend).
